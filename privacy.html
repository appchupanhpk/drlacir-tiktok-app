Privacy Policy

Effective date: 20 November 2026

This policy explains what data the Drlacir TikTok Auto Posting tool (“the Tool”) handles, why, where it is kept and how it can be deleted. The Tool is operated by Pham Kim Group, Vietnam (“we”, “us”). It is an internal tool used to produce and publish videos for our own TikTok account @drlacir.hn.nhn.kh. It is not offered to the public.

1. Who this policy applies to

It applies to the owner of the TikTok account connected to the Tool and to members of our team who use the Tool. The Tool does not collect data about other TikTok users or about the people who watch our videos.

2. Data we receive from TikTok

When the account owner signs in with TikTok and grants permission, TikTok sends us the following, and we use it only as described here:

DataPurposeWhere it is kept
Access token and refresh token (OAuth)To call the TikTok Content Posting API on behalf of the connected accountCloudflare Workers KV, in our own Cloudflare account. The access token, which expires after about 24 hours, is also passed to our production environment while a video is being uploaded and is not written to any file there
Open ID, granted scopes, token expiry timesTo identify the connected account and know when a token must be refreshedCloudflare Workers KV
Creator information returned by the Content Posting API (username, nickname, allowed privacy levels, maximum video duration, interaction settings)To confirm that the Tool is connected to @drlacir.hn.nhn.kh and to respect the posting options TikTok allowsRead when needed. Only the username is stored, alongside the tokens
Publish ID and posting statusTo track whether an upload succeededOur private GitHub repository, in the review queue record

We do not request access to the account’s followers, messages, comments, analytics or other users’ content, and the Tool does not read them.

3. Content the Tool creates

The Tool generates videos, headlines, captions and hashtags. Visuals are created with open-source AI image models and music is composed by the Tool; no third-party photos, videos or recordings are used as input. Generated content, the review queue and production records are stored in our private GitHub repository. Videos are sent to TikTok only after a team member approves them.

4. This website

This website is a static site hosted on GitHub Pages. It sets no cookies and contains no analytics, advertising or third-party scripts. GitHub, as the hosting provider, may process technical data such as IP addresses in its server logs under its own privacy statement.

5. Service providers

We rely on these providers to run the Tool. Each processes data under its own terms:

  • TikTok: authentication and video publishing via its official APIs.
  • Cloudflare: runs the sign-in (OAuth) service and stores the tokens in Workers KV.
  • GitHub: hosts our private code repository, the generated videos and captions, and this website.
  • Anthropic (Claude Code): provides the cloud environment in which videos are produced and uploaded.

We do not sell, rent or share TikTok data with anyone else, and we do not use it for advertising or profiling.

6. How the data is protected

  • The TikTok client secret and the tokens are never placed in our code repository or in this website.
  • The client secret is stored only as an encrypted secret setting of our Cloudflare Worker.
  • Requests to obtain a token from the sign-in service must present an access key known only to our team. The service returns tokens only to such requests.
  • Sign-in links expire after 10 minutes and can be used once. After sign-in, the service checks that the account is @drlacir.hn.nhn.kh and discards the tokens if it is not.

We rely on the standard security measures of the providers listed above and do not claim any additional certification.

7. Retention and deletion

  • Tokens are kept until the account is disconnected, permission is revoked, or the tokens expire. The refresh token lasts about one year.
  • On disconnect, the sign-in service asks TikTok to revoke the token and deletes the stored tokens.
  • The account owner can also remove the Tool’s access at any time in the TikTok app (Settings and privacy → Security and permissions → Manage app permissions). After that, the stored tokens can no longer be used.
  • Generated videos and production records are kept as our internal records until we delete them.

To request deletion of data connected to your TikTok account, contact us at the address below.

8. Children

The Tool is used only by our adult staff and is not directed at children.

9. Changes

If we change how the Tool handles data, we will update this page and its effective date.
